# Hi, I'm Mykola Rybiak

Software Engineering student focused on Java backend development with the Spring ecosystem.

I build REST APIs with Spring Boot, Spring MVC, Spring Data JPA, and Hibernate, secure them with Spring Security, store data in PostgreSQL, and ship them with Docker and CI/CD pipelines.
